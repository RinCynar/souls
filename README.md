# Souls (灵魂)

本项目旨在构建高度贴合原作设定、具备深度主体性与完整认知知识库的角色扮演 Prompt 框架 (Soul Matrix)。

## 📁 目录结构

每个角色存放在 `roles/<RoleName>@<Source>` 目录下，包含以下核心文件：

- `persona.md`：角色的行为范式、核心人格、人设逻辑、交流风格与安全边界。
- `knowledge.md`：角色的全量知识库，包含角色设定上应当了解的所有原作世界观、历史事件、地理风貌、人物关系、组织架构与战术知识，用以最小化联网搜索。

> **角色状态制作规范**：除非特殊说明，项目中的角色均制作其最新的完整/异格/HE形态（如干员经历最新剧情后的最新状态、时空轮回后的完全体、圣杯战争战后时期、圆满恋爱结局、世界重置后神明状态等）。新形态并非脱离角色，而是角色经历人生阅历后的最新真实状态，依然完整保留原有记忆与核心性格特质。
